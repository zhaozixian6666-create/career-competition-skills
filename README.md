# 职规赛内容引擎

**让每一段成长，都有证据；让每一份参赛材料，都经得起追问。**

这是一套面向全国大学生职业规划大赛的源码公开 AI Skills。学生只要讲出专业、经历和想去的方向，AI 就能沿着评分要求，把散落在课程、项目、作品、实习和反馈里的材料，组织成一条清晰的职业成长叙事：目标怎样确定，能力如何建立，行动带来什么结果，又为何作出调整。

**NexusAI 子贤学长出品 · 联系方式：HZCK717 · 禁止一切商用。**本仓库及压缩包中的原创内容遵循[非商业许可](LICENSE)；安装和个人学习可以，付费服务、商业产品及商业推广不得使用。

它把“职业选择、素材提取、评分映射、报告写作、逐页展示、现场陈述”串成一次对话。AI 应先交付可用内容，再指出最关键的事实与证据缺口；每项能力主张都要能回到学生本人做过的事。

**当前版本：v0.3.0，适用第四届规则（2026 年 10 月核对）。**重点完成**成长赛道内容制作与报告排版**。项目独立于赛事主办方；“国赛金奖强度”在这里指内容质量目标，不是获奖保证。

## 它能做什么

| 模块 | 学生给什么 | AI 交付什么 |
| --- | --- | --- |
| 参赛入口 | 年级、专业、赛道或一句模糊的参赛想法 | 识别成长/就业赛道、组别和当前应做的材料 |
| 职业定位 | 兴趣、课程、项目、想服务的人群 | 比较具体岗位，形成可调研的职业目标与能力画像 |
| 证据整理 | 成绩、作品、实验、竞赛、实习、志愿服务、反馈 | “岗位要求—本人行动—阶段结果—证明材料”证据链 |
| 生涯发展报告 | 已有故事、零散履历、草稿或证明材料 | 按三部分结构直接写正文，标出关键待核事实 |
| Word 报告排版 | 已确定的报告正文或现有 DOCX | 清晰的标题层级、自然分页、必要的证据对照与可编辑 Word 文件 |
| 展示 PPT 内容 | 报告底稿、图片与作品线索 | 内置 24 页结构的逐页选材、文案、证据和讲述重点 |
| 现场表达 | 报告、PPT 和证明材料 | 7 分钟陈述思路、问答要点与事实一致性检查 |

职业选择库现收录 **24 个代表性岗位**，覆盖机械与新工科、新医科、新文科、人工智能、社区和公益。每个方向都从典型任务、关键技能、可验证行动出发；人物和单位是进一步调研的线索，不是实时招聘或入职承诺。

## 核心方法

第四届成长赛道的三个评分指标是：**职业目标 25 分、学习实践行动 50 分、优化改进 25 分**。本项目用一条证据链组织内容：

```text
目标依据 → 岗位要求与个人差距 → 已做的学习实践 → 本人贡献与成果 → 反馈、调整与再次行动
```

这让报告、PPT 和答辩共享同一套事实。奖项、证书、实习证明、项目照片或播放量都可以成为材料，但必须说明它证明了什么、学生本人做了什么。缺少个人事实时，Skill 会写出可写的岗位分析并标注待补点；完整的虚构故事只作为明确标注的示范，不可仅改姓名后提交。

## 安装

将 `skills/` 下的三个文件夹复制到 Codex 的 Skills 目录：

```text
~/.codex/skills/
├── career-competition-guide/
│   └── SKILL.md
├── career-growth-content/
│   ├── SKILL.md
│   └── references/
└── career-report-layout/
    ├── SKILL.md
    ├── assets/
    ├── references/
    └── scripts/
```

Windows 默认位置为 `%USERPROFILE%\.codex\skills\`；如果设置了 `CODEX_HOME`，使用其中的 `skills` 目录。重新打开会话后，可直接用自然语言提出任务，也可显式调用 `$career-competition-guide`、`$career-growth-content` 或 `$career-report-layout`。

下载 ZIP 的用户先解压，再复制其中 `skills/` 下的三个完整文件夹。开发者可运行 `python scripts/validate_package.py` 校验引用，并用 `python scripts/build_package.py --version 0.3.0` 生成发布包。

## 四种直接用法

**从零开始**

> 我是大二新媒体专业学生，参加成长赛道，想先做生涯发展报告。我在校媒做过短视频，但还没确定目标职业。请帮我比较方向，并先写出目前能写的报告内容。

**把零散经历写成报告**

> 我想做智能制造系统工程师。这里有课程成绩、一次产线项目和实习证明。请提取我的具体贡献，按成长赛道结构直接写报告，并告诉我最值得补的两项证据。

**逐页制作展示内容**

> 报告已经完成。请按内置 24 页结构，先给我 1.1 到 2.5 每页能放什么、优先用哪项真实材料，再写可直接放进 PPT 的文案。

**制作可编辑 Word 报告**

> 这是我的成长赛道报告正文。请保持内容事实不变，用 `$career-report-layout` 排成正式 Word，逐页检查标题、证据表和分页。

学生可以上传现成简历、报告、截图、证书或直接讲故事，无需先填写完整问卷。已提供的信息应被继续使用。

## 当前范围

- **已完成**：参赛入口分流；第四届成长赛道规则映射；成长赛道报告、24 页展示内容和陈述内容的写作引导；24 个职业的研究起点；生涯发展报告的 Word 排版技能。
- **尚未做成独立 Skill**：就业赛道的简历、求职综合展示和辅助证明材料的完整内容工作流。入口 Skill 可以识别就业赛道并说明当届材料要求，但不能把它描述为已完成的就业模块。
- **内容与排版分工**：内容 Skill 负责论证、故事和证据；排版 Skill 负责 Word 的层级、分页和页面检查。正式提交的报告仍须导出 PDF，并核查字数、图表数量与文件大小。PPTX 文件生成取决于调用环境中的相应工具。

内置 24 页 PPT 结构是本项目的内容模板，**不是官方规定的页数**。学生已有其他结构时，Skill 应依照其要求调整。职业库、标杆人物和代表性单位也不是官方任职标准；正式成稿前，应核对目标地区和岗位层级的近期招聘、职业标准或访谈来源。

## 规则、来源与更新

第四届规则以[教育部通知及其赛道方案附件](https://www.moe.gov.cn/srcsite/A15/s7063/202610/t20261010_1453481.html)为准。仓库中的[规则基线](第四届大赛规则基线.md)记录本项目使用的评分、材料和环节信息；[历届资料索引](历届资料索引与变化.md)仅用于理解变化，不能覆盖现行规定。职业人物索引附有公开来源，动态招聘、行业数据和政策结论需要在使用时重新核对日期与适用范围。

本项目不收录学生的个人资料、第三方案例原件或商业模板文件，也不隶属于教育部或大赛组委会。参赛资格、地方赛安排与最终提交要求，请以当届官方通知和学校要求为准。
