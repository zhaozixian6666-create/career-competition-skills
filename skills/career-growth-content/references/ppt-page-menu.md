# 成长赛道展示PPT逐页选材菜单

这是给学生看的内容选择清单。封面、22张编号页、封底共24页，每个编号独占一页。每页“可选”列出能展示的内容类型，学生只需勾选自己真实拥有的项目、经历或材料；“优先”指出最能支撑该页结论的组合，不代表必须凑齐。AI应先从已有报告和材料替学生预勾，再只问缺失的关键事实。某项没有就跳过或标为待补，不编造。外部政策、招聘和行业资料可由AI协助查证。

使用时向学生展示少量相邻页的清单，例如：“我从你的报告里找到1.1的参访经历和照片。你还可以选当时观察到的问题、第一次尝试；请补一句你亲眼看到什么。”学生选定后，AI直接写该页文案，不能只返回清单。

## 封面

- **可选**：目标职业名称；一句与职业目标相符的主标题；学校、专业、年级和组别；本人姓名；本人照片。
- **优先**：清楚写出目标职业和参赛身份，职业名称与2.5一致。照片和口号可省。
- **具体指示**：告诉AI目标职业的准确名称、学校专业和组别；AI用一句话形成主标题，不给学生添加未经确认的身份。

## 第一部分：职业认知

### 1.1 职业缘起：为什么想做

- **可选**：亲历的一件事；当时看见的具体问题；受到影响的人或服务对象；自己的感受与价值判断；第一次因此采取的行动；与事件有关的照片、日记或作品。
- **优先**：一件真实事件 + 看见的问题 + 它为何让你关注这个职业。证据优先选亲历记录，单纯抒情不够。
- **具体指示**：选一件亲身经历，讲清何时何地、你看见谁遇到什么问题、你当时做了什么，以及为什么想到目标职业；AI将其写成“事件—问题—职业动机”。

### 1.2 职业启蒙：怎样走近

- **可选**：一位引路人及其具体影响；第一次课程、参访、访谈或体验；第一次动手尝试；原先认识与新认识的变化；随后继续探索的行动。
- **优先**：关键人物或事件 + 你因此采取的实际探索。只讲“谁鼓励我”不足以证明职业启蒙。
- **具体指示**：指出引路人或首次接触行业的活动，复述一个具体的认识变化，再说出你随后做的第一项探索；不要只提供人物头衔。

### 1.3 职业内涵：职业实际做什么

- **可选**：服务对象；2至4项日常任务；典型工作流程；岗位产出；常用技能或工具；安全、伦理与协作要求；从业者或岗位说明的原话。
- **优先**：真实任务 + 典型产出 + 对应能力，并附职业标准、招聘说明或访谈来源。
- **具体指示**：说出该岗位至少两项实际任务、各自产出和所需技能；AI用可核实的岗位资料核对，避免只解释职业名称。

### 1.4 国家与行业人才需求

- **可选**：直接相关的国家或地方政策任务；产业项目或公共服务需求；人才培养举措；有来源的人才需求数据；目标岗位参与解决问题的具体环节。
- **优先**：1条最相关的权威依据 + 说明它为何需要该岗位。政策发布机构、日期和适用范围须可查。
- **具体指示**：先告诉AI目标地区、行业和岗位；AI选择最相关的政策或需求资料，写清“提出了什么任务—该岗位在哪个环节发挥作用”，保留来源和日期。

### 1.5 职业前景

- **可选**：校招或入门岗位；典型用人单位；从初级到进阶的路径；技术变化带来的新任务；持续学习要求；现实的不确定性。
- **优先**：可进入的起步岗位 + 后续成长方向 + 支撑判断的招聘或行业资料。不要用行业规模直接推断个人就业结果。
- **具体指示**：选一个毕业后可能应聘的入门岗位，再指出下一阶段可能承担的更复杂任务；AI核对招聘信息，不承诺薪酬或就业结果。

## 第二部分：职业探索与目标确认

### 2.1 榜样人物探索

- **可选**：访谈或观察的从业者；其真实工作场景；他/她遇到的难题；对技能和素养的建议；你原先判断被验证或修正的地方；访谈笔记或公开资料。
- **优先**：你从对方工作中学到的2至3条岗位事实 + 对自己选择的影响。人物头衔只是背景。
- **具体指示**：提供访谈、观察或公开材料中的两条具体发现，尤其是难题与能力要求；说清其中哪一点改变了你对职业的判断。

### 2.2 自我认知

- **可选**：专业能力的具体表现；一次快速学习或跨领域应用；合作沟通的任务记录；导师或服务对象反馈；当前短板；测评结果作为辅助线索。
- **优先**：岗位要求 + 个人任务证据 + 现有差距。优先放实际表现及反馈，测评不能单独证明胜任力。
- **具体指示**：针对两项岗位能力，各讲一件自己做过的事、结果和外部反馈；再指出一项短板及判断依据，AI据此形成能力对照。

### 2.3 目标确立

- **可选**：当时的初步目标岗位；作出选择的依据；与目标的主要差距；专业学习路径；项目或实习探索路径；拟定的阶段目标。
- **优先**：明确岗位 + 最关键的能力差距 + 准备采取的2至3项行动。这里讲计划，不提前宣称成果。
- **具体指示**：说出当时拟定的岗位、最缺的能力和对应补齐方式；每项行动要能落到课程、项目、访谈或实践，不写“全面提升”。

### 2.4 标杆企业岗位要求

- **可选**：2至3家代表性单位及岗位；工作任务；专业与学历条件；必备技能；经验要求；通用素质；不同单位要求的共性和差异。
- **优先**：与学生目标一致的真实实习或校招岗位 + 共性要求 + 招聘来源与日期。优先条件和必备条件分开。
- **具体指示**：提供或让AI查找2至3个同类入门岗位，逐个摘出任务、必备条件和优先条件；AI汇总共性，并标注企业、地区和发布时间。

### 2.5 目标确认与职业画像

- **可选**：最终目标岗位；服务对象与典型任务；入门必备知识技能；综合素质与职业规范；未来进阶能力；个人目前最急需补齐的能力。
- **优先**：岗位任务 + 入门能力清单 + 本人优先补齐项，并能追溯至2.1和2.4。
- **具体指示**：从榜样调研和招聘要求中确认一个最终岗位，列出三项最重要的入门能力；指出自己先补哪项、为什么。

## 第三部分：成长计划与能力基础

### 3.1 成长计划

- **可选**：各学年的学习目标；要修的关键课程；工具或技能训练；项目、实习或调研节点；每阶段检验方法；实际完成状态。
- **优先**：原计划中的时间节点 + 对应岗位能力 + 可检验的行动。未来事项要标为计划。
- **具体指示**：按制定计划时的年级列出阶段目标，每阶段写“要补的能力—要做的事—完成标志”；区分当时计划与后来实际执行。

### 3.2 学业筑基

- **可选**：相关课程与成绩；课程设计；实验任务；技能训练；作品或测试结果；教师评价；知识迁移到项目的例子。
- **优先**：最相关的2至3项学习任务 + 已形成的能力或作品。成绩单可证明学习基础，但需解释与职业的关系。
- **具体指示**：选两三门课程或实验，分别说明完成的任务、学到的岗位相关方法和可展示的作品或成绩；不要整页罗列所有课程。

### 3.3 项目实践经历概览

- **可选**：1至3个相关项目；任务来源；本人角色；用到的工具和方法；初步产出；对应岗位能力；项目任务书或作品样本。
- **优先**：项目任务 + 本人负责部分 + 对应岗位技能。本页只做概览，把困难与步骤留给4.2/4.3，结果留给5.1/5.2。
- **具体指示**：每个项目只回答“项目要解决什么—我负责什么—使用什么技能”，优先选择后来能在4.2至5.2继续讲清的项目。

## 第四部分：学习实践与行动过程

### 4.1 学习实践

- **可选**：课堂或实验的连续训练；社会调研；三下乡或百千万工程中与职业相关的任务；学习日志；方法迭代；阶段性作品；从不会到会的变化。
- **优先**：持续投入的时间线 + 关键学习动作 + 可见进步。活动名称和参与时长不能代替学习结果。
- **具体指示**：挑出一段持续学习过程，写起点水平、练习或实践动作、后来能完成的任务；课堂和社会实践都要说明与目标岗位的联系。

### 4.2 行动实践一

- **可选**：真实实习或项目背景；任务目标；本人职责；关键难题；采取的步骤和方法；导师或客户的阶段反馈；过程记录。
- **优先**：一项真实任务 + 本人如何解决关键问题 + 阶段反馈。单位标识和合影只能辅助。
- **具体指示**：讲清任务是谁提出的、本人负责哪一步、遇到什么障碍、尝试了哪些办法、得到什么阶段反馈；按时间顺序写，不把团队工作都算作本人贡献。

### 4.3 行动实践二

- **可选**：另一段实践或同项目的独立阶段；新的任务与责任；不同于4.2的技能重点；更复杂的问题；改进的方法；过程反馈。
- **优先**：区别于4.2的任务 + 本人新承担的动作 + 能力进步。不能把同一过程换标题重复展示。
- **具体指示**：选择第二段不同任务；若来自同一项目，明确它是另一阶段，并指出责任、方法或问题比4.2发生了什么变化。

## 第五部分：阶段成果与岗位匹配

### 5.1 阶段成果一

- **可选**：4.2的交付件；测试或服务结果；使用者、客户或导师评价；被采纳的方案；有口径的数据；奖项或证书；个人贡献说明。
- **优先**：实际交付件 + 被使用或评价的情况 + 本人贡献。数字须有记录，奖项需连接到具体工作。
- **具体指示**：对应4.2说出最终交付了什么、谁验收或使用、效果如何、本人做了哪一部分；有数据时附原始记录或统计口径。

### 5.2 阶段成果二

- **可选**：4.3的另一项交付件；验证结果；版本对比；采纳或验收情况；受益对象反馈；相较第一项成果的能力提升。
- **优先**：第二项独立成果 + 可核验反馈 + 相比5.1的新进步。
- **具体指示**：对应4.3说出第二项成果和评价，再用一句话指出相比5.1，自己解决问题的范围、难度或独立性如何提高。

### 5.3 岗位能力匹配与外部评价

- **可选**：2.5的岗位能力清单；3至5部分的对应证据；HR、主管、导师或服务对象的具体评价；尚未达标项；下一步补强方向。
- **优先**：岗位要求—个人证据—外部反馈—剩余差距的对照。只有真实评价才能引用评价者身份和原话。
- **具体指示**：从2.5选三项核心能力，逐项匹配一件个人作品或任务；如有主管、HR或导师的真实评价，准确注明评价者和时间；末尾保留一项未达标能力。

## 第六部分：自我评估与发展

### 6.1 自我评估与未来学习计划

- **可选**：原计划与实际结果；一次失败或反馈；不足的原因；已调整的方法；调整后的测试或作品；下一阶段学习任务和检验标准。
- **优先**：一次真实的“评估—调整—再验证”过程 + 下一步具体任务。若尚未再验证，如实写正在执行。
- **具体指示**：写出原计划、一次具体反馈或失败、你改变了哪种做法、改变后出现什么结果；再给下一步任务的时间和检验标准。

### 6.2 综合能力素养全景与职业愿景

- **可选**：专业知识；实践技能；学习与协作能力；职业精神；各项最强证据；尚需提升的一项；希望服务的人群或解决的问题。
- **优先**：3项最有证据的能力 + 1项仍需提升的能力 + 具体职业愿景，不使用无依据的百分比。
- **具体指示**：从前面页面各挑一项专业、实践和综合素养证据，说明目前能承担什么任务；指出尚不能胜任的部分和希望服务的对象。

### 6.3 发展规划与初心回扣

- **可选**：下一学期里程碑；毕业起步岗位；继续学习或实践机会；中期发展方向；对1.1初心的新理解；可检验的下一步。
- **优先**：回应最初动机 + 下一阶段最具体的一步 + 与职业目标相符的起步岗位。与6.1的复盘内容分开。
- **具体指示**：回到1.1的那件事，讲实践后你对它有了什么新理解；写下一学期的一步行动和毕业后希望应聘的入门岗位。

## 封底

- **可选**：本人一句职业承诺或口号；姓名；愿意公开的学校邮箱等联系方式。
- **优先**：从真实经历中提炼的一句话。私人联系方式完全可省。
- **具体指示**：提供一句你愿意亲口说出的职业承诺；没有现成表述时，AI从1.1的动机和4至6部分的行动拟两三个短句供你选择。

## 输出给学生的方式

1. 学生初次要求做PPT时，先列出整套24页的简短目录，并标出哪些页已能从现有材料生成、哪些页仍需事实。通常按3至5页一组展示上面的可选项与优先项；学生要求一次看完整清单时，直接展示全部页面。允许学生说“选第1和第3项”或直接发材料。
2. 每组先建议最有力的搭配，并说明已有材料能支撑什么；同时展示每页“具体指示”，让学生知道需要提供哪些事实。学生无相关经历时给出可如实呈现的替代内容，不要求凑齐菜单。
3. 收到选择后，直接写对应页面的标题、核心句、可放入PPT的短文案、证据出处及讲述要点。未核实信息标注待核，不把选项本身当作已发生事实。
