# 成长赛道职业库

本库帮助学生把宽泛的职业兴趣收窄为可调研的目标岗位，并把岗位任务、能力要求与个人经历对应起来。它是**选题和取证指南**，不是官方职业标准、实时招聘数据库或个人胜任力结论。职业名称可能因企业而异；每次使用都应核对学生所关注地区、行业、单位及具体招聘岗位。不得把库中“可用证据”写成学生已经拥有的经历。

## 使用顺序

1. 先问学生学科专业、想解决的问题、希望服务的对象、接触过的项目和想去的行业。学生已有明确目标时直接定位条目；目标很宽时，用相近岗位的任务边界帮助比较，不替学生单凭热门程度定目标。
2. 读对应条目，向学生解释岗位日常任务及所需能力。把每项能力转换成普通学生能回答的问题，检查是否有课程、实验、作品、实习或反馈作为个人证据。
3. 到招聘、职业标准或从业者调研中核实岗位名称、职责和入门要求。至少保存具体来源、发布日期、地区、岗位层级；对实习/校招与资深岗位分开看。
4. 将核实后的岗位任务用于PPT 1.3，将国家/行业需求和职业前景另行查证后用于1.4/1.5；招聘证据用于2.4，能力清单用于2.5，个人经历用于3至5部分，差距与改进用于5.3/6.1。报告也按同一事实底稿写。

## 学生不知道选什么时

- 喜欢设计实体产品、画图、做样机：比较机械产品设计、医疗器械研发、汽车电子。
- 喜欢现场设备、产线、调试和问题排查：比较制造工艺、工业机器人应用、自动化控制、智能制造系统。
- 喜欢数据、编程和模型：比较工业数据分析、嵌入式软件、人工智能算法、大模型应用、人工智能治理。
- 喜欢实验、疾病问题和健康服务：比较药物研发、医疗器械研发、临床医生；先核对医学教育与执业门槛。
- 喜欢文化研究、保护和真实叙事：比较数字人文、文化遗产保护、纪录片策划。
- 喜欢直接服务居民、组织协作、推动社会问题解决：比较社区治理、社区营造、公益项目、公益传播与筹款。

这些只是探索入口。让学生各选最多三个候选职业，再比较具体任务、已有经历、入门要求和可调研资源，形成职业目标确定过程。

## 每条职业的最小结构

- **岗位边界**：与相近岗位的工作重点区别是什么，可能对应哪些不同企业称谓。
- **典型任务与产出**：岗位常做的具体工作、交付件和服务对象。条目中的任务是候选，不代表所有企业都如此。
- **能力与证据**：专业知识、技术工具、问题解决、协作沟通、安全质量等能力分别可以由哪些真实行动侧面证明。证书只能证明相应考试或培训，不能自动证明工作表现。
- **学生追问**：用普通语言问“做过什么、具体负责什么、遇到什么问题、结果怎样、谁能证明”。
- **核实方向**：针对目标地区和入门岗位检索近期校招/实习信息；必要时核对人社部门职业标准、行业规范、从业者访谈。保留来源和日期，避免无来源的人才缺口、薪酬及前景数字。
- **标杆与去向**：找可核对的领域人物，说明应学习其哪种方法；列与岗位任务相关的代表性组织并核实是否有适合学生的招聘。名人和知名机构不能替代学生本人调研。

## 空白条目模板

```markdown
### [具体岗位名称]
- 岗位边界：[与相邻岗位有何区别；企业常用别名]
- 典型任务与产出：[任务1→交付件；任务2→交付件]
- 能力—可验证行动：[能力1→学生可能提供的真实任务/作品/反馈；能力2→...]
- 向学生问：[两三个能问出个人行动和结果的问题]
- 核实：[目标地区、岗位层级、具体招聘/职业标准/访谈的来源及日期]
- 标杆与去向：[人物、可学习的方法、公开来源；2家左右与岗位相关的组织及其业务关联]
```

### 来源和更新规则

优先级为具体单位的近期校招/实习岗位说明、现行国家职业技能标准或行业标准、行业组织与院校的正式资料、从业者访谈记录。不同来源回答的问题不同：招聘说明证明某单位当时招什么人，职业标准描述规范要求，访谈反映特定工作场景；不能把单个样本推为整个行业。库中条目不包含未经逐条核实的市场规模、工资、人才缺口和政策结论。面向学生成稿时应重新核实动态信息。
