# 就业赛道 PPT 逐页逻辑与选材

原始结构来自用户提供的《就业赛道PPT逐页内容规划表.xlsx》，并整理为[Word 参考稿](../assets/就业赛道PPT内容逻辑_逐页Word版.docx)。以下每一行是选材选项，不要求学生凑齐，更不是官方固定页数。制作时先依据真实 JD 找能力要求，再依据学生本人的经历决定保留哪些页。6 分钟主题陈述优先讲 P6/P7/P9、P11、P14/P17/P18、P24、P26/P27；P29–P30 仅供内部制作。

## 开场与职业目标：P1–P9

| 页 | 要证明什么 | 优先放什么；请学生提供什么 |
| --- | --- | --- |
| P1 封面 | 一句话明确目标入门岗位与个人定位。 | 具体岗位名、姓名/学校/专业及一句基于真实经历的主张；与 P28 呼应。 |
| P2 全篇结构 | 评委能看到目标、胜任力、潜力三段论证。 | 三段短标题及对应页段，不堆素材。 |
| P3 章节过渡 | 职业选择有调研依据。 | 一句概括目标岗位为何进入视野；快速过渡。 |
| P4 政策与社会需求 | 目标工作服务哪项现实任务。 | 只选直接关联岗位工作的政策条款，给文件名、日期、原文要点；不要凭政策推断人才缺口。 |
| P5 行业与就业市场 | 目标地区的相关岗位有可核需求。 | 可靠的招聘变化、岗位类型或统计，注明地区、年份、口径、来源；无可靠数据时不写缺口人数。 |
| P6 岗位工作画像 | 知道入门岗位的实际工作。 | 4–6 个典型任务、工作流程、交付物、协作对象、评价标准；请提供 JD 或从业者资料。 |
| P7 招聘需求分析 | 能力要求来自真实岗位。 | 目标地区、企业、岗位层级、采集日期与 JD 原文；归纳重复出现的任务和能力，样本少时不计算比例。 |
| P8 从业者访谈，可选 | 一线经验补足 JD。 | 真实访谈对象/岗位/时间/方式、可公开的话和个人所得结论；未访谈则删去或改公开资料研究，连接 P11。 |
| P9 目标单位与岗位 | 目标落到一家机构的具体岗位。 | 单位业务、岗位名称、地点、招聘批次与关键 JD 要求、信息来源日期；不暗示已录用。 |

## 岗位胜任力：P10–P24

| 页 | 要证明什么 | 优先放什么；请学生提供什么 |
| --- | --- | --- |
| P10 章节过渡 | 从岗位要求转到个人证据。 | 一句提示后文按能力逐项举证；快速过渡。 |
| P11 胜任力模型 | 后文证据与 JD 对得上。 | 依据 P7/P9 和有效访谈整理专业知识、专业技能、综合素质、实习实践；每项指向实际证据页，不造能力分数。 |
| P12 专业学习 | 课程知识支撑岗位任务。 | 相关核心课程、成绩、具体作业及应用场景；请提供成绩单和作品。 |
| P13 学校资源，可选 | 实际利用资源形成了能力。 | 参与的实验室、导师或校企项目及本人任务；仅有平台头衔时合并入 P12 或删去。 |
| P14 专业知识与技能 | 能用方法交付岗位所需结果。 | 选 3–4 项技能，逐项写工具/方法、真实场景、本人交付物和评价；请提供原件或记录。 |
| P15 竞赛总览，可选 | 相关竞赛证明具体能力。 | 赛事、作品、本人角色、奖项证明；弱关联奖项让位于项目。 |
| P16 代表性竞赛，可选 | 在复杂任务里作出专业判断。 | 最相关作品的问题、方法、迭代、结果、评审反馈与个人分工；不虚构工作量百分比。 |
| P17 项目主案例 | 能解决一个岗位相关的实际问题。 | 问题与约束、本人方法与取舍、交付物、结果、复盘；优先原始记录和前后版本，团队成果须区分。 |
| P18 实习主案例 | 在真实流程中承担过岗位相关任务。 | 单位、部门、岗位、时间、一项具体任务、本人操作、产出与主管反馈；证明仅证参与，能力靠产出。 |
| P19 第二段实习或实践，可选 | 补足第一段没有覆盖的能力。 | 互补经历的任务与产出；没有第二段可用课程项目、科研或社会实践，不编造。 |
| P20 沟通与协作 | 具体协作问题由我推动解决。 | 分工、沟通记录、冲突或协调方法、交付结果；学生干部头衔只是背景。 |
| P21 服务意识与职业精神，可选 | 理解服务对象并承担责任。 | 与岗位有关的志愿或公共实践：服务需求、本人行动、反馈与改进；无关联时删减。 |
| P22 困难与自我管理 | 面对压力有可复述的处理方法。 | 一次任务冲突或技术难题、优先级判断、资源协调、结果和复盘；避免无证据的绝对化表述。 |
| P23 关键荣誉，可选 | 外部认可与能力证据一致。 | 少量岗位相关奖项或真实录用意向，指回对应项目；尊重隐私与展示授权。 |
| P24 人岗匹配总表 | JD 关键要求都有证据或清楚的差距。 | 左列引用 P9 要求，右列写本人行动、交付物和证据页；空缺明确写在 P26–P27 如何补。 |

## 发展潜力与收尾：P25–P30

| 页 | 要证明什么 | 优先放什么；请学生提供什么 |
| --- | --- | --- |
| P25 章节过渡 | 从现有能力转向未来成长。 | 一句过渡，快速进入 P26。 |
| P26 变化与学习 | 已识别岗位变化并采取行动。 | 一项直接相关的变化、已经学习的方法或已做项目，以及目前差距；已做与计划分开。 |
| P27 阶段发展规划 | 下一步可执行且能检查。 | 近期/中期/长期任务、对应能力和里程碑；与 P24 缺口对齐，不臆测职级晋升年限。 |
| P28 收尾 | 留下一条真实、最强的录用理由。 | 呼应 P1 的岗位与个人主张，不引入新事实；这是正式展示的结尾。 |
| P29 素材清单，内部 | 证据原件和展示页可互相找到。 | 证书、JD、作品、记录与页码，以及授权/打码事项；提交前删除此页。 |
| P30 语言词库，内部 | 页面表述具体一致。 | 岗位动词、方法、交付物、结果的写法；提交前删除此页。 |

## 成稿检查

P7/P9 的要求应进入 P11，在 P14–P22 找到真实行动，最后由 P24 回收。核对政策、市场数据、JD、访谈和个人成果的来源、日期、范围与证明。简历、PPT、辅助证明中的时间、职责和结果必须一致。只有个人证据较强的页才适合占现场讲述时间；不用为了凑页数增加弱证据。
