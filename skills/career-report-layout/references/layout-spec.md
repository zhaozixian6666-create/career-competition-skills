# 成长赛道生涯发展报告版式规范

## 页面信息顺序

默认首屏依次为具体目标职业的报告标题、赛道与专业信息、必要的示范或待核说明、两三句开篇结论。随后沿用职业目标、成长实践、未来发展的正文结构。用户明确要求设计扉页时，可单独制作一页封面：报告名称、目标职业、一句话职业主张、选手姓名与专业阶段、参赛组别必须能快速扫到；缺失的姓名和指导教师留待填写，不编造。虚构示范的性质在封面和正文中持续标明。章节名称与内容技能的报告模板保持一致，已有不同结构时遵从用户的成稿。

## 参考模板的使用边界

用户提供的《成长赛道 创意光谱职规赛模板》提供了封面字段和“职业目标—实践计划—未来规划”的内容框架，也提示在学业、竞赛、实习成果旁放可核查佐证。它本身是一份填写框架，含占位提示、创业方向示例、推广信息及未核实的数据，不应当作可直接提交的事实或成品视觉规范。只借用信息位置与章节功能；视觉上依据用户要求采用简约、留白充分的编辑设计。不要复制模板里的联系方式、品牌标志、口号或无来源数值。

## 字体与层级

- 无扉页时，主标题用 `Title` 样式，16到18磅、黑色、左对齐或居中；有扉页时，目标职业可用32到40磅作为主视觉，报告名称在其上方清楚标注。标题必须说明目标职业和文档用途。移除 Word 默认 Title 样式可能带入的蓝线、蓝字和主题色。
- 一级标题12到13磅、黑色粗体；二级标题10.5到11磅、黑色粗体。标题与后续至少一段保持同页，不让单独的标题留在页底。
- 正文10.5到11磅、黑色中文字体，行距约1.25到1.4倍；首行缩进两个汉字左右。段后留少量空白，不靠密集回车制造节奏。
- 示范标识、来源说明和页脚可用8.5到9磅深灰色。对比度应能在打印后仍清楚可读。
- 页码放页脚，页眉若使用，只显示简短文档名称或组别。封面通常不显示页码。不要在报告上模拟赛事官方标志。

## 页面与证据

按内容自然分页。无封面时两页篇幅通常最紧凑；用户要求扉页时，封面单独计页，正文仍须保持可读，不能为凑页数缩小字体或挤压行距。需要手动分页时，优先放在大节之前，并检查前一页是否留下大片空白。避免一段只剩一行落到下一页。

文字段落承载主叙事。只有岗位要求与个人证据、行动前后数据等需要横向比较时才使用表格或图；三行左右的证据对照表可以作为评委快速定位材料的索引，但不能复制整段正文。图表总数遵从官方限制。不要把完整报告塞进表格、卡片或侧栏。证书缩略图、作品截图应证明正文中的具体主张，避免为填满页面而堆放。

每个关键经历应在页面上容易定位：时间或任务、本人的动作、问题、结果、证明材料。数据须标注口径；团队结果与个人贡献在文字上明确分开。对模拟报告保留虚构说明；对真实报告只展示已核实事实。

## 交付前检查

逐页查看标题是否完整、字符是否缺失、段落是否越界、表格是否断行、页码是否正常、行间是否拥挤。导出PDF后再检查一遍，并确认官方规定的字数、图表数量与文件大小。无法渲染时交付可编辑稿并诚实说明页面效果尚未完成最终检验。
